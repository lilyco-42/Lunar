# Lunar — ESP32-C3 智能语音助手

## 作品简介

Lunar 是一款基于 ESP32-C3 微控制器的多模态智能语音助手。它集成了环境感知、语音交互和 Web 远程控制三大功能于一体，以极低成本实现了"小型智能家居终端"的完整体验。

## 核心功能

- **语音问答**：本地唤醒词"路娜"检测（ESP-SR）→ 云端语音识别（STT）→ 大语言模型理解（LLM）→ 语音合成（TTS）→ 喇叭播放
- **环境感知**：实时采集温度（DS18B20）、一氧化碳浓度（MQ-7）、空气质量（MQ-135）、光照强度（BH1750）、电流/电压/功率（INA219），并在 0.96 寸 OLED 屏上显示摘要
- **智能传感器查询**：用户可通过语音自然地询问"现在温度多少"、"空气质量怎么样"，LLM 自动解析意图并调用传感器数据回答
- **手机 Web 控制**：内嵌轻量级 SPA 网页，支持局域网直连和外网穿透（frp/MQTT），手机浏览器即可查看传感器仪表盘、发送文字让设备朗读

## 技术架构

| 层级 | 技术选型 |
|------|----------|
| 主控 | ESP32-C3（RISC-V, WiFi/BLE） |
| 固件框架 | ESP-IDF v5.4 (C) |
| 唤醒词 | ESP-SR（本地免费，中文自定义） |
| 前端 | 纯 HTML/CSS/JS 单文件 SPA（嵌入 Flash） |
| 云中继 | Node.js Express（代理 STT/LLM/TTS API） |
| 外网穿透 | frp + MQTT 双通道 |

## 设计亮点

1. **全链路语音闭环**：从本地唤醒词"路娜"到云端理解再到本地播放，用户体验流畅自然
2. **LLM Tool Call 架构**：大模型通过工具调用机制直接读取真实传感器数据，回答基于实测而非猜测
3. **极低成本方案**：全部硬件约 50 元以内，云端采用 Serverless/免费 Broker，适合个人 DIY
4. **渐进式网络**：优先局域网直连，支持 MQTT 远程指令和 frp Web 穿透，断网时本地功能不受影响

## 数据流

1. **语音问答**：唤醒词"路娜"触发 → 录音 → 云端 STT → LLM → TTS → 本地播放
2. **传感器查询**：用户问"温度多少" → LLM 解析意图 → 调 REST API 取传感器数据 → 语音回答
3. **Web 控制**：手机浏览器 → HTTP API 读传感器 / 发指令
