传感器总览

I2C 总线 I2C
SCL = GPIO4    SDA = GPIO5    频率 = 100 kHz
三个设备共用同一对 SDA/SCL，地址各不相同，无需额外区分。
建议在 SDA、SCL 各加 4.7kΩ 上拉电阻到 3.3V（大多数模块自带上拉）。
OLED SSD1306 I2C
VCC → 3.3V   GND → GND
SCL → GPIO4   SDA → GPIO5
I2C 地址 0x3C
BH1750 光照 I2C
VCC → 3.3V   GND → GND
SCL → GPIO4   SDA → GPIO5
ADDR → GND  (地址 0x23)
INA219 电源监测 I2C
VCC → 3.3V   GND → GND
SCL → GPIO4   SDA → GPIO5
A0 → GND   A1 → GND  (地址 0x40)
VIN+ → 被测电源正极   VIN- → 负载端
电流串联流过 VIN+ → VIN- (内置 0.1Ω 采样)
MAX9814 麦克风 ADC
VDD → 3.3V   GND → GND
OUT → GPIO0 (ADC1_CH0)
GAIN → 悬空 (60dB)
AR → 悬空 (自动恢复)
DHT11 温湿度 1-Wire
VCC → 3.3V   GND → GND
DATA → GPIO7
3 脚模块自带板上拉电阻，无需外接
DS18B20 防水温度 1-Wire
红 (VCC) → 3.3V   黑 (GND) → GND
黄 (DATA) → GPIO6
⚠ 必须接 4.7kΩ 上拉: GPIO6 ↔ 3.3V
2.2kΩ~10kΩ 均可；GPIO10 不可用 (被 flash 占用)
MQ-7 一氧化碳 ADC
VCC → 5V ⚠   GND → GND
AO → GPIO1 (ADC1_CH1)
DO → 不接
⚠ 必须加分压: 0~5V → 0~2.5V
MQ-135 空气质量 ADC
VCC → 5V ⚠   GND → GND
AO → GPIO3 (ADC1_CH3)
DO → 不接
⚠ 必须加分压: 0~5V → 0~2.5V

MQ 传感器分压电路

MQ 模块 5V 供电时，AO 输出 0~5V，ESP32-C3 ADC 量程约 0~2.5V（11dB 衰减），必须分压 才能接入，否则烧毁引脚。
两个等值电阻（10kΩ / 4.7kΩ / 1kΩ 均可，但要两个阻值一样）: 
MQ AO ──┬── R1 ── GPIO (ADC)
        │
        R2
        │
       GND
推荐 R1 = R2 = 10kΩ，将 0~5V 降为 0~2.5V。
MQ-7 分压后接 GPIO1，MQ-135 分压后接 GPIO3。两个传感器各需一组分压。

GND 全部共地
功耗估算：ESP32-C3 (~80mA) + MQ-7 加热器 (~150mA) + MQ-135 加热器 (~150mA) + 其他 (~230mA) ≈ 610mA  → 建议使用 5V / 2A 电源。

关键提醒

✅ I2C 总线三设备地址不冲突：0x23 (BH1750) · 0x3C (OLED) · 0x40 (INA219)
✅ 部分模块自带 I2C 上拉电阻，多个并接一组 4.7kΩ 即可
✅ ESP32-C3 内部上拉 ~45kΩ，太弱，DS18B20 等必须外接上拉
⚠ DS18B20：DATA 线外接 4.7kΩ~10kΩ 上拉到 3.3V，否则不通信
⚠ MQ-7 / MQ-135：5V 供电，AO 必须经分压再接 GPIO，直连会烧 ADC 引脚
