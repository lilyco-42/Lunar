## 2. 核心功能

- **语音问答**：关键词唤醒 → 说话 → STT 识别 → LLM 理解 → TTS 合成 → 喇叭播放
- **传感器查询**：识别传感器相关意图后，读取本地传感器数据并语音回复
- **日常对话**：通用问答走 LLM API
- **OLED 显示**：显示 IP 地址、传感器摘要、设备状态
- **Web 控制**：手机浏览器访问，局域网直连，外网穿透

### 数据流三条路径

1. **语音问答**：唤醒词触发 → 录音 → 云端 STT → LLM → TTS → 本地播放
2. **传感器查询**：用户问“温度多少” → LLM 解析意图 → 调 REST API 取传感器数据 → 回答
3. **Web 控制**：手机浏览器 → HTTP API 读传感器 / 发指令

## 4. 固件设计

### 技术选型

| 层 | 选择 | 原因 |
|---|---|---|
| 开发框架 | ESP-IDF (C) | I2S 音频、DSP 唤醒词支持完整 |
| 唤醒词 | ESP-SR (乐鑫官方) | 本地免费，中文唤醒词自定义 |
| Web 服务 | ESP-HTTPD | 托管静态网页 + REST API |
| 音频流 | PCM 16kHz 16bit 单声道，WebSocket | 满足 STT 需求，无需编解码 |
| 外网穿透 | MQTT + frp | MQTT 做指令通道，frp 做 Web 穿透 |

### 模块划分

```text
固件（单线程事件循环）
├── audio_capture   → ADC DMA 采集 MAX9814，I2S 输出到 PAM8403
├── wake_word       → ESP-SR 本地检测，命中后触发录音状态
├── cloud_relay     → WebSocket / HTTP 上传音频到中转服务
├── sensor_task     → 定时轮询全部传感器 (1Hz)，缓存最新值
├── oled_display    → 显示 IP / 传感器摘要 / 状态
├── web_server      → 托管 SPA 页面，提供 REST API
├── mqtt_client     → 连接公共 broker，外网指令中转
└── wifi_manager    → SmartConfig 配网 + 连接重试
```

### GPIO 分配（初步）

| 外设 | 协议 | 引脚 |
|------|------|------|
| OLED (SSD1306) | I2C | SDA=GPIO5, SCL=GPIO4 |
| BH1750 | I2C | 同上（共享总线） |
| INA219 | I2C | 同上 |
| MAX9814 | ADC | GPIO0 (ADC1_CH0) |
| PAM8403 | I2S DAC | 待定（需确认 I2S 引出） |
| DS18B20 | OneWire | GPIO3 |
| MQ-7 | ADC | GPIO2 (ADC1_CH1) |
| MQ-135 | ADC | GPIO1 (ADC1_CH2) |

### Web REST API

```http
GET  /api/sensors              → JSON {temp, co, air, light, current, power}
GET  /api/sensor/:id           → 单个传感器最新读数
GET  /api/status               → WiFi 状态, 在线时长, 内存
POST /api/speak                → {text: "..."} 发送 TTS 文本到设备播放
GET  /api/conversation/history → 最近对话记录
```

## 6. 云中转服务

### 职责

AWS API Gateway + Lambda（或阿里云函数计算），极低成本：

- **STT 代理**：接收 PCM 音频 → 转发给百度/阿里 STT → 返回文字
- **LLM 代理**：接收文字 → 做 sensors tool 定义 → 转发给 DeepSeek/通义千问 → 返回文字
- **TTS 代理**：接收文字 → 转发给百度/阿里 TTS → 返回 MP3 流
- **MQTT 服务器**：AWS IoT Core / EMQ X 免费版，做 ESP ↔ 手机外网指令中转

### LLM Tool Definition（关键）

```json
{
  "tools": [{
    "name": "read_sensor",
    "description": "读取传感器数据",
    "parameters": {
      "sensor": "temp | co | air | light | current | power | all"
    }
  }, {
    "name": "get_device_status",
    "description": "获取设备在线状态和信息"
  }]
}
```

LLM 判断用户意图为读取传感器时，自动调用 tools，云端框架解析后 HTTP 请求 ESP 的 `/api/sensors`，结果注入 LLM 生成自然语言回答。

## 7. 外网访问方案

| 层 | 方案 | 说明 |
|---|---|---|
| 网页穿透 | frp (frps 云服务器) | 映射 ESP 80 端口到公网域名 |
| 备用指令通道 | MQTT | 如果 frp 不通，手机通过 MQTT 发指令 |
| 配网 | ESP SmartConfig | 手机 APP/网页 发 WiFi 密码到设备 |
